Team chat in the app

Team chat step 2 (ORCH-1115, draft picked in ORCH-1098). In a ticket chat you can add another workspace, see whose message is whose, and open Chat info with who added whom. On the computer the same chat has the Add dialog, chips and chat info (ORCH-1174).
