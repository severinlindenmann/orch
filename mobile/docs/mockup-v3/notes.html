Mockup boundary

Simulated: microphone/camera capture, transcription, helper execution, PDF pages, network links, uploads, QR recognition, invitations, push, receipts and native system integration. Review entries reset their scenario state; ordinary navigation preserves mounted screens and scroll. No runtime network requests are made.
