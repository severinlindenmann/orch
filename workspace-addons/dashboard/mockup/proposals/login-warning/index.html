What I chose, and you can change

No new word

It is called "login" everywhere, with the tool's name in front: "Claude Code login", "GitHub login". The button is "Renew". No new page and no new menu entry.

Warning starts 3 days before

Early enough for a weekend, late enough that it is not noise. No setting for it.

A code may have to be pasted once

When you open the dashboard from another computer, the Claude sign-in page ends with a code. The window has one field for it. It goes straight to the tool and is not kept.

The phone warns, the computer renews

Renewing from the phone is not part of this ticket.

Tools that tell no end date

Some logins (GitHub on this computer) give no end date. For those there is no early warning, only the "ran out" notice the moment the login stops working.
