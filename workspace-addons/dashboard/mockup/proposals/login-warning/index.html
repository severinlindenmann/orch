What I chose, and you can change

New words: see new-words.md

Everything else is existing words: login, key, connection, Renew, helper, ticket.

Early warning only where the tool gives an end date

The main helper tells it, three days ahead. GitHub, Databricks and connections only work or do not, so they warn once they stopped.

The phone warns, the computer renews

Renewing from the phone is not part of this ticket.

Never a secret on screen

A key is replaced in the key entry and never shown. A pasted sign-in code goes straight to the tool.
