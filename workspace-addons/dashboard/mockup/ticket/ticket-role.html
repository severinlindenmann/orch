Its job

Every 6 hours it installs the newest version of orch on a clean test computer, runs the tests and clicks through the pages like a person would.

What it finds becomes a report for you. It fixes nothing itself.

Full instructions

One repeating helper checks the newest version on a clean test install every 6 hours. It replaces the separate look-and-wording role and overlaps the daily Dashboard tester.

  1. Before a helper starts, a quick check (no AI) looks whether the newest version changed since the last run. If not, the run ends there.
  2. Run the end-to-end tests.
  3. Try orch with no add-ons, with all add-ons, and with each add-on turned off in turn: make a ticket, start a helper, answer a card, send back, accept, move it through the lanes. Every page must load without errors.
  4. Click through what was finished since the last run, with the eyes of an IT engineer, a business manager and a marketing person, at three screen widths.
  5. Every failure becomes a problem report; a finished feature without a test becomes a report too. Fix nothing.
  6. Keep a short log of what was checked. Stop after 75 minutes.
