Each sub add-on

Meetings

Needs a short test
Way in today
Yogurt records and writes the transcript on your notebook; a script hands over each finished meeting.
Backup way in
The transcript Teams made itself, through the Microsoft MCP access.
The catch
Everyone on the call must agree before you record. One day of testing shows whether Yogurt says reliably when a meeting is finished.

Calendar

Ready to build
Way in today
The Calendar app on your notebook, after one click to allow it.
Backup way in
The Outlook calendar through the Microsoft MCP access.
The catch
The notebook must be on and awake.

Mail: Outlook

Ready to build
Way in today
Microsoft MCP access: read, search, make drafts. No send.
Backup way in
Outlook web in the orch browser, driven by a script.
The catch
The browser way breaks when Microsoft changes the page.

Mail: private

Ready to build
Way in today
The Mail app on your notebook, or the mail server with an app password.
Backup way in
None.
The catch
Gmail needs a Google sign-in.

Messages: Teams

Needs a short test
Way in today
Microsoft MCP access: read chats, search. No send.
Backup way in
Teams web in the orch browser, driven by a script.
The catch
The browser way is fragile and needs you signed in in the orch browser on your notebook.

Messages: WhatsApp

Only partly possible
Way in today
A chat you export by hand and add.
Backup way in
WhatsApp Web in a browser: possible, against WhatsApp’s rules, off unless you choose it.
The catch
The browser way can get the account blocked.

Notes

Ready to build
Way in today
The Obsidian folder, read on your notebook.
Backup way in
The folder synced to the workspace machine.
The catch
Helpers write only into “From helpers”.

When a way in stops working

Browser scripts break when Microsoft or WhatsApp change their pages. Every way in checks itself once a day.

When one fails, the tile says so with one “Try again”, and a ticket is made to fix the script. What already arrived stays. The Microsoft MCP access is used first wherever it works.

Suggested order

  1. A short test week on your notebook. The private connection, the Yogurt hand-over, Calendar access, the Microsoft MCP access for Outlook and Teams, one browser script for Teams web.
  2. Personal with sub add-ons, and Notes. Proves the tiles, the rules and how helpers reach it.
  3. The small orch app. With the private connection and the waiting requests.
  4. Meetings, then Calendar. Through Yogurt and the Calendar app.
  5. Outlook mail and Teams. Through the Microsoft MCP access; browser scripts as backup.
  6. WhatsApp. Chat export; the browser way only if you choose it.
Makes one ticket. Nothing is connected by it.
