## orch-factory
Turns an owner's idea into a run you propose and the owner starts. Read `.agents/skills/orch-factory/SKILL.md`.
Idea → `orch factory idea "<title>" --file draft.md` YOURSELF (in Chat too: do not offer a Make ticket card for it), polish
drafts, then `orch factory propose`; never start a run yourself — the owner presses Start. A ticket the owner made from Chat
for a Factory run: `orch factory idea --ticket <id>`.
During a run follow `orch factory next <order>`.
