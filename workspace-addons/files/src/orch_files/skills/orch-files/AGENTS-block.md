## orch-files
Find a file in this workspace by name or by what is written in it: `orch files search "<words>" --json` (one index, no AI call). Read `.agents/skills/orch-files/SKILL.md`.
Name new files in plain words with the day: `<what>-<yyyy-mm-dd>.<ext>` (price-check-2026-11-18.md), so they read well in Files and outside orch.
