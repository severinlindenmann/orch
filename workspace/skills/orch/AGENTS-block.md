## orch workspace
Every piece of work is tracked as an orch ticket. Before you start: run `orch ticket list`; if none fits, run `orch ticket new "<title>"`.
Keep it current: add checklist items (`orch check add <id> "<text>"`) and mark each done with evidence (`orch check done <id> <c> --evidence ...`) before you finish. A checklist item counts as done only with evidence.
Read the relay inbox at session start (`orch relay inbox`), if relay is connected.
Details: `.agents/skills/orch/SKILL.md`. When waiting for an answer, save context and pause.
